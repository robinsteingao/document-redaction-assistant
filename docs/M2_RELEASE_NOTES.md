# M2 试点可用能力说明

> 版本: 0.2.0-m2
> 日期: 2026-05-22
> 状态: 试点能力工程版，仍不作为完整客户安装包发布。

## 已完成

- 增加复核工作区生成能力，输出候选字段 JSON 和本地 HTML 复核页。
- 支持客户词库，允许把客户自定义单位、项目名、人员或技术词纳入识别。
- 支持复核决策:
  - `redact`: 脱敏。
  - `keep`: 保留。
  - `pseudonym`: 假名化。
  - `range`: 区间化。
  - `mask`: 强脱敏。
- 增强脱敏影响提示:
  - 技术指标缺失时提示 TRL 判断可能降级。
  - 金额缺失时提示经济效益分析缺少可计算依据。
  - 金额强脱敏时提示经济效益分析可能降级。
- 增加本地还原预演，展示脱敏版和本地还原版片段。
- `build-package` 命令现在同步输出:
  - `review_candidates.json`
  - `restore_preview.json`
  - `review_workspace.html`
  - `redaction_review_report.md`

## 仍未完成

- 尚未提供桌面安装包。
- HTML 复核页当前为静态预览，不直接回写决策。
- 尚未实现映射表加密。
- 尚未接入 OCR。
- 尚未对接 STPE-AI 后端沙箱导入接口。
