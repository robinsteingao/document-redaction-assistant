# 文档安全脱敏助手 M24.2 MVP 与 M25 开发愿景

> 状态：产品开发规划
> 范围：仅适用于 `products/document_redaction_assistant` 独立支线
> 边界：不改变 STPE-AI 主系统评分规则、TRL/readiness 口径、数据库 schema 或报告强结论措辞

## 1. 背景

M24/M24.1 已补齐客户自定义字段处理、评价影响提醒、《使用必读》、运行态盲测包和桌面壳基础体验。但投用初期反馈表明，客户最容易卡在批量处理、路径填写、复核 JSON、预检/进度信息理解和问题反馈材料收集上。

同时，PaddleOCR 已推进到 3.7.0，PP-OCRv6、PaddleOCR-VL、PP-StructureV3 等能力显示出更强的多语言 OCR、表格/版面解析和结构化输出潜力。该方向适合作为 M25 愿景进入规划，但不应挤占 M24.2 的客户体验闭环。

## 2. M24.2 MVP：客户体验增强

### 2.1 目标

让客户在不理解 JSON、命令行、错误码和内部字段名的情况下，完成一次文件夹级批量脱敏、复核、重新生成和问题反馈。

### 2.2 本轮纳入范围

1. **复核工作区按钮化**
   - 在 `review_workspace.html` 中为每个候选字段提供“保留原样、遮盖隐藏、替换假名、保留区间”选择。
   - 页面自动生成 `review_decisions.json`，客户无需手写 JSON。
   - 高影响字段选择强脱敏时显示评价降级风险提示。

2. **批量处理总览**
   - 基于既有文件夹/多项目目录能力，输出批量总览摘要。
   - 展示成功、失败、跳过、需转换、需 OCR、需复核数量。
   - 每个项目保留独立输出目录、映射表、复核页和报告。

3. **预检/进度业务化分组**
   - 将预检信息按“可直接处理、需转换、需 OCR、暂不支持、跳过、缺失路径”分组。
   - 每组给出客户下一步操作建议。
   - 进度摘要继续保留技术支持用原始详情，但默认先显示业务摘要。

4. **一键技术支持包**
   - 输出不含原文、不含本地映射表、不含密钥的诊断 JSON/Markdown。
   - 包含版本号、OCR 状态、文件类型统计、预检摘要、任务状态、错误摘要和输出文件存在性。

5. **路径辅助与输出目录打开提示**
   - 不做浏览器伪文件选择器，不承诺浏览器可直接读取本地真实路径。
   - 强化路径填写示例、短路径建议、输出目录一键复制/打开提示。

### 2.3 本轮不纳入范围

- PaddleOCR 3.7 / PP-OCRv6 正式升级。
- PaddleOCR-VL、PP-StructureV3、复杂版面解析。
- 新增真实上传能力。
- 修改 STPE-AI 主系统评分、TRL/readiness、schema 或报告强结论。
- 承诺“无隐私残留”或替代法务/安全审查。

## 3. M25 开发愿景：OCR 与文档结构化升级

M25 作为下一阶段愿景记录，不进入 M24.2 MVP 实施范围。

### 3.1 愿景目标

将 OCR 升级从“能识别扫描件文字”提升为“复杂文档可结构化解析、可复核、可保真脱敏”。

### 3.2 候选能力

1. PaddleOCR 3.7 / PP-OCRv6 本地离线接入。
2. RapidOCR 与 PaddleOCR 双引擎 fallback。
3. OCR 置信度阈值与低置信复核队列。
4. 表格/Excel/WPS 单元格级脱敏与坐标追踪。
5. 扫描 PDF 版面结构化输出 Markdown/JSON。
6. OCR/结构化性能基线：页耗时、总耗时、内存、低置信比例。
7. 模型/规则/运行时分层更新，避免每次都重发 300MB+ 完整包。

### 3.3 M25 前置条件

- M24.2 客户操作闭环完成并通过运行态验收。
- `.xls/.wps` 真实样本专项验证完成。
- PaddleOCR 新版本离线 wheelhouse、模型体积、Windows CPU 推理速度完成基线测试。
- 明确 PaddleOCR 输出只作为识别线索，低置信结果必须进入人工复核。

## 4. 验收口径

M24.2 验收以“客户可完成一次批量脱敏闭环”为准：

- 文件夹输入可生成批量总览。
- 客户可在复核页点选字段处理方式并导出决策。
- 重新生成后决策生效。
- 预检/进度摘要不要求客户阅读原始 JSON。
- 技术支持包不含原文、本地映射表或密钥。
- 运行态桌面壳黄金路径通过。

M25 验收另行制定，不使用 M24.2 的通过结果替代 OCR/结构化专项验证。

## 5. M24.2 交付说明

M24.2 新增：复核页按钮选择、批量总览、预检/进度业务化分组、技术支持包、客户端加密映射表。技术支持包不包含原文、本地加密映射表、加密口令或密钥。

M25 愿景：PaddleOCR 3.7 / PP-OCRv6、OCR 置信度复核、表格/版面结构化解析。该能力不属于 M24.2 交付范围。
