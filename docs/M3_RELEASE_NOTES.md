# M3 真实试点准备能力说明

> 版本: 0.3.0-m3
> 日期: 2026-05-22
> 状态: 真实试点准备工程版，仍不作为完整客户安装包发布。

## 已完成

- 增加本地映射表加密封装:
  - `encrypt-mapping`
  - `decrypt-mapping`
  - `batch-build --mapping-passphrase`
- 扫描 PDF 预检:
  - 疑似图片型 PDF 标记为 `ocr_required`。
  - 不再把 PDF 内部对象伪文本静默上传。
- XLSX 表格结构保留:
  - 每行保留 sheet、row、cell ref 和脱敏后的单元格内容。
  - 支撑后续效益表、指标表和证据表进入 STPE-AI 沙箱。
- 多项目批处理:
  - 每个子目录作为一个 `project_alias_id`。
  - 批量生成脱敏上传包、复核页、还原预演、沙箱导入包和批处理清单。
- STPE-AI 沙箱导入包:
  - 生成 `sandbox_import_package.json`。
  - 明确不包含原始文件和本地映射表。
- 本地 HTML 复核页增强:
  - 增加可编辑复核决策 JSON。
  - 支持导出 `review_decisions.json`，再由 CLI 重新生成上传包。

## 边界

- 当前加密封装用于本地原型验证，客户正式交付前仍应替换为经过审查的标准加密库或系统级密钥管理。
- OCR 仍未接入真实模型；当前只做扫描 PDF 识别和阻断提示。
- HTML 复核页仍是本地静态页面，不是完整桌面应用。
- STPE-AI 沙箱导入包尚未接入后端 API。
