# M5 试点闭环能力说明

> 版本: 0.5.0-m5
> 日期: 2026-05-22
> 状态: 试点闭环工程版，仍不是完整安装器。

## 已完成

- STPE-AI 沙箱导入从“校验”升级为“可落库”:
  - 使用 `project_alias_id` 生成沙箱项目 ID。
  - 写入脱敏项目记录。
  - 将脱敏文本块写入项目文件记录。
  - 不写入原始文件和本地映射表。
- 新增 OCR 适配器状态接口:
  - `ocr-status` CLI 命令。
  - 默认不要求 OCR，文本型 PDF、DOCX、XLSX 不受影响。
  - 如果配置了 `DRA_OCR_ENGINE`，可检查 RapidOCR/PaddleOCR 依赖是否存在。
- 新增静态桌面壳:
  - `build-desktop-shell` CLI 命令。
  - 生成 `index.html` 和 `app_config.json`。
  - 作为正式桌面应用前的试点入口。

## 已验证

- 沙箱导入包可写入 DataManager 的项目和文件记录。
- 写入的文件记录只包含脱敏文本。
- 静态桌面壳包含导入文件、字段复核、生成上传包、报告还原四步。
- OCR 状态接口可在无 OCR 依赖环境下返回 `not_configured`，不影响文本型材料处理。

## 仍未完成

- 尚未提供安装器。
- 静态桌面壳尚未绑定本地服务。
- 沙箱导入后尚未自动触发 STPE-AI 全量评估。
- OCR 真实识别能力仍未接入。

## M6 建议

- 接入本地服务，让桌面壳可直接选择文件和生成包。
- 沙箱导入后触发 STPE-AI 评估与报告生成。
- 接入 RapidOCR 或 PaddleOCR mobile。
- 替换工程加密封装为正式加密依赖。
