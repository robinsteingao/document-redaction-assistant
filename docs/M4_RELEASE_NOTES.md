> 日期: 2026-05-22
> 状态: 客户试点准备工程版，仍不是完整安装包。

## 已完成

- 增加 OCR 质量接口:
  - `ocr_required` 文件默认阻断上传。
  - 低文本量 PDF 给出复核提示。
- 增强本地 HTML 复核页:
  - 可编辑复核决策 JSON。
  - 可导出 `review_decisions.json`。
- 增加客户试点包生成:
  - `START_HERE.md`
  - `USER_GUIDE.md`
  - `SECURITY_BOUNDARY.md`
  - `PILOT_ACCEPTANCE_CHECKLIST.md`
  - 样例项目材料
  - `trial_manifest.json`
- 增加 STPE-AI 后端沙箱导入校验:
  - `POST /api/redaction-sandbox/import`
  - 拒绝包含原始文件或本地映射表的上传包。
  - 返回项目代号、文件数、脱敏块数量、映射哈希和提示。
