# M22 Release Notes: 用户视角批处理闭环

日期: 2026-05-25

## 本阶段目标

把 M21 暴露的真实使用问题收敛到最小可测闭环: 用户不需要理解后台接口，能够先预检文件夹，再启动后台处理，并看到进度和最终输出目录。

## 新增能力

- 文件夹递归预检: 区分可处理文件、旧版 Office/WPS 待转换文件、跳过文件和缺失路径。
- 后台任务: `/start-build` 创建任务，`/job-status` 查询进度和结果。
- 桌面壳交互: 新增“预检文件”“PDF OCR 模式”“处理进度”。
- 输出目录保护: 相对目录自动写到用户输出根目录，安装目录不可写时回退，结果返回 `outputs.output_dir`。
- 快速 OCR 模式: PDF 默认先识别 1 页，适合内部测试和大目录预览。

## 修复

- 修复包内 `generated` 目录无写权限导致任务完成解析后写包失败的问题。
- 修复金额区间替换值包含原始金额字符串的问题。
- 预检阶段跳过 `.json` 复制清单等非文档文件。
