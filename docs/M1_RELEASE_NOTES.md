# M1 原型发布说明

> 版本: 0.1.0-m1
> 日期: 2026-05-22
> 状态: 工程原型，不作为客户安装包发布。

## 已完成

- 建立独立产品目录 `products/document_redaction_assistant`。
- 实现 DOCX、XLSX、文本型 PDF、TXT、Markdown 的本地解析入口。
- 实现本地规则识别和稳定占位符映射。
- 实现金额区间化，避免经济效益字段完全丢失。
- 保留技术指标和验证信息，用于 TRL 分析。
- 生成脱敏上传包 `redaction_upload_package.json`。
- 本地保存映射表 `local_mapping.private.json`，不进入上传包。
- 支持基于本地映射表还原报告文本。
- 提供命令行入口和自动化测试。

## 未完成

- 尚未提供桌面向导界面。
- 尚未接入 OCR。
- 尚未实现 DOC、XLS、WPS 专有格式兼容。
- 尚未实现映射表加密。
- 尚未对接 STPE-AI 后端沙箱导入接口。
