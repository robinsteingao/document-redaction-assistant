# 外发边界

本文只说明文档安全脱敏助手当前已经做到和明确没做到的事。它不是安全审查结论。

## 当前产物

默认识别覆盖带标签的项目名、单位、联系人，以及电话、邮箱、`HT-` 合同编号、专利号、软著号和金额。技术指标、验证信息默认保留。金额默认区间化。

身份证号、银行卡号、地址尚未实现。无标签人名和单位不会自动识别。

`redaction_upload_package.json` 是可复核的脱敏文本包。它不是已销毁原文的 PDF、DOCX 或 XLSX。本地映射表不进入上传包。

## 隐藏通道

生成结果包时会只读检查这些通道，报告里只有类型和数量，不放通道原文：

- DOCX：页眉、页脚、脚注、尾注、批注、修订、文本框、嵌入对象、文档属性。
- XLSX：隐藏表、非常隐表、批注、定义名称、文档属性。
- PDF：文档属性、注释、附件、表单、脚本。没有 PDF 解析库时标为未核验。
- DOC、XLS、WPS：转换前标为需要转换，不标成已检查。

有发现或未核验时，结果包不可直接外发。

## 残留自检

自检只回搜本次应替换的已识别字段。命中后结果包不可直接外发。自检通过也不表示材料可以外发。

## 外发副本

以下是工作分支上的安全修订口径，不代表已发布的 v0.26.0 已经包含这些修复。v0.26.0 的外发能力存在已确认的阻断及回写缺陷，不应作为可靠外发依据。

修订后的目标行为：

- 每次任务在 `external_release/` 下创建独立批次。只使用本次返回的 `external_release` 路径和清单，不要整体发送包含历史批次的父目录。
- 批次先在临时目录生成，验证后再发布。新任务不覆盖、清空或删除历史批次和用户文件；清单只列本次生成件，阻断文件不得出现在本次目录。
- 残留自检缺失、状态未知、未扫描或未明确通过时，不生成外发文件。源文件发生变化、读取失败或验证失败时同样阻断。
- DOCX/XLSX 回写必须检查 XML 文本、属性与关系；图片、嵌入内容和其他无法验证的部件保守阻断，不默认原样携带。只读通道盘点不等于已经完成清理。
- Word 未修改部分的文本片段及样式应保留，不以合并整段文字代替定位替换。
- 外发文件采用代号命名，不沿用可能含敏感信息的原文件名。来源对照应留在本地，不通过发送整个输出根目录来交付。
- XLSX 的隐藏表、非常隐表或批注仍是阻断项。
- **本轮暂停全部 PDF 外发副本生成**，包括文字型、扫描型、混合型和旋转 PDF。PDF 解析、OCR 和脱敏文本上传包功能不因此关闭。恢复 PDF 外发前，必须另行完成逐页分类、坐标变换、输出重开与视觉验收。

外发批次不应包含本地映射表（含加密映射表与口令）、旧版注册申请或授权文件。生成件须重新打开验证，不能将“文件不存在”“解析失败”或“没有可提取的文字”解释为已清理。

DOCX/XLSX 校验依赖 `lxml`、`python-docx`、`openpyxl`，缺失时保守阻断。安装方法见 [安装与 OCR 说明](INSTALL_AND_OCR.md)。这不改变基础文本包的轻依赖边界。

外发副本仍需人工复核。本工具不替代法务审查、涉密审查或安全审计。
