文档安全脱敏助手 M24.2 使用必读
==================================

一、先看结论
1. 本工具在本机离线处理文件，原始文件不上传。
2. 普通用户优先双击 app\start_desktop_app.bat 打开界面。
3. 生成的结果请以界面“输出目录”为准查找。
4. local_mapping.private.enc 是本地加密映射表，只留在本机，不要上传或外发；请牢记加密口令，丢失后无法还原。
5. review_workspace.html 里可以直接点选字段处理方式；如需复制复核文件，review_decisions.json 可用“记事本”、Notepad++、VS Code 打开。

二、首次部署流程
1. 解压到短路径，例如 D:\DRA 或 C:\DRA，避免桌面深层目录、空格、特殊字符和网络盘。
2. 如包内提供 app\install_offline_ocr.bat，先双击安装 OCR 依赖。
3. 如包内提供 app\validate_offline_ocr.bat，再双击校验 OCR。
4. 双击 app\start_desktop_app.bat，等待浏览器自动打开“文档安全脱敏助手”。
5. 浏览器未自动打开时，手动访问 http://127.0.0.1:8765。

三、日常操作方法（M22 用户流程合并版）
1. 在界面填写项目代号，例如 test_project_01，并设置“本地映射表加密口令”。
2. 在“待处理文件或文件夹路径”中填写完整路径。每行一个文件；也可以填写一个文件夹做批量脱敏。
3. 点击“预检文件”，重点看“可直接处理文件数、需先转换文件数、跳过文件数、暂不支持文件数、路径不存在、推荐 OCR 模式”。
4. PDF 较多时先选择“快速预览”，确认链路和识别效果后再做完整处理。
5. 点击“开始生成脱敏结果包”，等待“处理进度摘要”显示 completed。
6. 打开输出目录，重点查看 redaction_upload_package.json、sandbox_import_package.json、redaction_review_report.md、review_workspace.html 和 local_mapping.private.enc。
7. 如任务长时间运行，可点击“取消当前任务”；失败任务可点击“重试失败任务”。
8. 遇到问题时点击“生成技术支持包”，将界面生成的 JSON 复制给技术支持；技术支持包不包含原文、本地加密映射表、加密口令或密钥。

四、预检结果和处理进度怎么看
界面会先显示摘要，普通用户只需看摘要；下方“原始详情”是给技术支持复制定位问题用的，不需要逐行理解。
- 可直接处理文件数：可以进入脱敏流程的文件数量。
- 需先转换文件数：旧版 DOC/XLS/WPS，会先尝试本地转换。
- 跳过文件数：系统自动忽略的临时文件、压缩包、清单等。
- 暂不支持文件数：当前版本无法处理的文件。
- 路径不存在：填写的文件或文件夹路径不存在，请检查复制是否完整。
- 任务状态 completed：已完成；failed：失败；cancelled：已取消。
- 输出目录：最终结果所在文件夹，以这里显示为准。

五、自定义字段处理方式
1. 先正常生成一次结果包。
2. 打开输出目录中的 review_workspace.html。
3. 在页面表格中直接选择“保留原样、遮盖隐藏、替换为假名、保留区间”。
4. 点击“导出复核选择文件”，得到 review_decisions.json。
5. 将生成的 JSON 内容粘贴回界面的“自定义字段处理方式（可选）”，重新生成。
6. 如果强制隐藏技术指标、验证信息、金额、专利等关键字段，可能影响后续评价；确需这样做时再勾选“确认接受评价降级风险”。

六、常见报错处理
1. 检查 OCR 后显示“未配置 OCR 引擎”
   - 先确认是否运行过 app\install_offline_ocr.bat。
   - 再运行 app\validate_offline_ocr.bat。
   - 只处理 DOCX、XLSX、文本型 PDF、TXT 时，未配置 OCR 通常不影响；扫描件 PDF 需要 OCR。
2. 点击“开始生成脱敏结果包”后提示 the application cant be start,user installation couldn't be completed
   - 多数是本地服务或运行时未启动成功。请关闭窗口，重新双击 app\start_desktop_app.bat。
   - 确认解压路径较短，且不要放在网络盘或权限受限目录。
   - 如仍失败，右键以管理员身份运行 app\start_desktop_app.bat，或联系技术支持并提供截图。
3. 浏览器提示本地服务未连接 / Failed to fetch
   - 先确认 app\start_desktop_app.bat 的命令行窗口没有关闭。
   - 手动访问 http://127.0.0.1:8765。
   - 仍失败时运行 app\start_local_service.bat 后刷新页面。
4. 输出目录找不到
   - 相对输出目录会保存到“文档\文档安全脱敏助手输出”。
   - 以处理进度摘要里的“输出目录”为准。

七、批量脱敏
投用初期可直接把一个文件夹路径填入“待处理文件或文件夹路径”。系统会递归识别可处理文件，并为同一项目生成一组结果文件。多个项目建议分项目分别运行，避免把不同项目的本地映射表混在一起。

八、边界提醒
“评价影响提醒”只提示脱敏选择是否可能影响后续评价，不等于无隐私残留，也不等于 STPE-AI 最终评价一定不受影响。

九、M25 愿景说明
PaddleOCR 3.7 / PP-OCRv6、OCR 置信度复核、表格/Excel/WPS 单元格级脱敏和扫描 PDF 版面结构化解析属于 M25 愿景，不属于 M24.2 当前交付范围。
